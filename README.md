## Build instruction

Prerequisites
  - Python https://www.python.org/downloads/
  - Renpy sdk https://www.renpy.org/latest.html for building

Build 
  - In Renpy, select preferences, change project directory to the parent directory of the `study_buddy`, then return to main menu
  - Select `study_buddy` project, and select Build distributions
    - Choose your platform, then build the project
  - Resulting packages should be available in the parent directory of `study_buddy`
